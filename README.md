# NetSpecter

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://python.org)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux-lightgrey)]()
[![License](https://img.shields.io/badge/License-MIT-green.svg)]()

**NetSpecter** – инструмент для управления сетевым трафиком в изолированной лабораторной среде.  
Позволяет блокировать сайты на уровне пакетов, подменять QUIC-соединения, работать с прокси-списками и привязывать их к отдельным процессам.

*Read this in [Russian](#russian) | Читать на [русском](#russian)*

---

## Возможности / Features

- **DPI-блокировка сайтов** – перехват TLS/QUIC трафика и мгновенный обрыв соединения.
- **Подмена QUIC (UDP → TCP SYN)** – обход защиты браузеров, принудительный сброс.
- **Прокси-менеджер** – автоматическая загрузка списков, многопоточная проверка, фильтр по странам.
- **Привязка прокси к процессам** – для точечного обхода блокировок.
- **Игровые серверы** – добавление IP:Port для обхода банов (рандомизация IP).
- **Автозагрузка** – запуск вместе с системой.
- **Простой GUI** – тёмная тема, все настройки в одном окне.

---

## Установка / Installation

1. Установи Python 3.8 или новее.
2. Установи зависимости:
   ```bash
   pip install PyQt6 scapy pydivert
   ```
3. Для Windows также установи **Npcap** (https://npcap.com) в режиме *"WinPcap API-compatible Mode"*.
4. Скачай или склонируй репозиторий:
   ```bash
   git clone https://github.com/yourname/netspecter.git
   cd netspecter
   ```

---

## Запуск / Usage

- **Обычный запуск** (требуются права администратора):
  ```bash
  python osn.py
  ```
- **Windows** – используй приложенный `launcher.bat`, он сам запросит права администратора.
- После открытия интерфейса нажми **Start Engine**, добавь домены во вкладке DPI и проверь работу (например, открой `youtube.com`).

---

## Настройка / Configuration

- **DPI / Domains** – введи домены для блокировки (по одному на строку).
- **Proxy Manager** – нажми *Download Proxies*, затем *Check All*. Рабочие прокси появятся в таблице.
- **Process Binding** – выбери процесс и назначь ему прокси.
- **Settings** – включи автозагрузку, выбери тестовый URL.

Все настройки сохраняются в папке `%USERPROFILE%\.xtech_netspecter`.

## <a name="russian"></a> Русская версия

**NetSpecter** – утилита для фильтрации трафика и управления прокси в изолированной среде.  
Блокировка сайтов через глубокий анализ пакетов, сброс QUIC-соединений, автоматическая загрузка и проверка прокси, привязка к процессам, обход игровых банов.

### Установка (кратко)
```bash
pip install PyQt6 scapy pydivert
python osn.py
```

### Основные функции
- **Блокировка доменов** – работает на уровне TLS/QUIC, обрывает соединение мгновенно.
- **Прокси-менеджер** – скачивает списки из 12 источников, проверяет их работоспособность.
- **Фильтр по странам** – можно оставить прокси только из нужной страны.
- **Привязка к процессам** – разные программы могут идти через разные прокси или напрямую.
- **Автозагрузка** – программа сама добавит себя в реестр (Windows).
