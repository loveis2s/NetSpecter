# NetSpecter
NetSpecter — инструмент для фильтрации трафика и управления прокси. Блокировка сайтов через DPI, подмена QUIC-пакетов, обход блокировок в играх с рандомизацией IP, встроенный прокси-менеджер с загрузкой и проверкой списков, фильтр по странам, привязка прокси к процессам. Удобный GUI, автозагрузка, низкое потребление ресурсов.
