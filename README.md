# NetSpecter

Инструмент для фильтрации трафика и управления прокси в изолированной среде.

## Возможности

- Блокировка сайтов на уровне пакетов (DPI, обрыв TLS/QUIC).
- Подмена QUIC (UDP → TCP SYN) для предотвращения обхода блокировки.
- Прокси-менеджер: загрузка из 12 источников, проверка, фильтр по странам.
- Привязка прокси к процессам.
- Добавление игровых серверов для обхода банов.
- Автозагрузка с системой.

## Установка

pip install PyQt6 scapy pydivert

Для Windows также установи Npcap (https://npcap.com) с опцией "WinPcap API-compatible Mode".

## Запуск

Запусти `launcher.bat` от имени администратора или выполни:

python osn.py

## Использование

1. Добавь домены во вкладке DPI.
2. Нажми Start Engine.
3. Проверь блокировку, открыв сайт в браузере.

## Предупреждение

Только для образовательных целей в изолированной лаборатории.
